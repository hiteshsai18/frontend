How to integrate bootstrap to your html page ?

Content delivery/ Content distribution :-

copy and paste the link for bootstrap in the <head> tag.
place <script> tag with logic for execution using javascript at the end of <body> tag. 

Responsive breakpoints :-

Breakpoint      Class infix     Dimensions
X-small            None            <576px
Small              sm              >=576px
Medium             md              >=768px
Large              lg              >=992px
Extra large        xl              >=1200px
Extra extra large  xxl             >=1400px
